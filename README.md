# 培芽教育 · PEIYA EDUCATION

面向意大利雷焦艾米利亚（Reggio Emilia）华侨华人子女的中文·英语·艺术课外培训机构筹备项目。

## 项目结构

| 目录 | 内容 |
|---|---|
| `logo/` | 品牌 Logo：定稿主标（单绿嫩芽徽章）、形状变体、底色变体的画板源文件（`.dc.html`）与设计画布 |
| `策划书/` | 项目策划书（`peiya-business-plan.html`）及四份调研简报：华人社区市场、意大利学校作息与证书体系、成本与定价、法律形式与合规 |
| `网站/` | 宣传官网（`peiya-website.html`），面向家长，手机端优先 |

## 关键结论（v1.1）

- 品牌：单一绿色（#2E7D4F）嫩芽徽章，注册名建议 Centro Culturale Peiya（意法律限制非认证机构使用 "scuola"）
- 市场：40 公里辐射圈目标儿童约 1,200–1,600 名；盈亏平衡约 60 名学员
- 财务：启动资金约 €28,000（含 3 个月预备金）
- 节奏：2026 Q4 注册与场地 → 2027 年 1 月周六中文试点班 → 暑期夏令营 → 2027 年 9 月正式开学

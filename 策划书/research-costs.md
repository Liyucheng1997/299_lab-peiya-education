# 调研简报 3：Reggio Emilia 成本与市场定价

调研日期 2026-08-20。标记：[实] 真实挂牌/公开价 / [估] 推算 / [缺] 未找到。

## 商业租金（Reggio Emilia）

- 写字楼均价 **€9.5/m²/月**（老城区 €10.8）；商铺均价 €6.5/m²/月，近半年跌约 6.6% [实]
- 实例：San Prospero/Tribunale 区 150 m² 办公 **€1,050/月**（约 €7/m²）；Porta Castello 250 m² 商铺 €1,600/月 [实]
- **100-200 m² 可用空间工作区间：€700-1,900/月；半市中心 150 m² ≈ €1,000-1,500/月** [估]

一次性成本（商业租约标准 6+6 年）：
- 押金：通常 **3 个月租金** [实]
- 注册税：年租金 1%（房东有增值税号时），房客房东各半，30 天内注册 [实]
- 中介费：年租金 10-15% + 22% IVA（约 €1,200-2,700）[估]

## 水电杂费（按 150 m² 估）

- 电：€100-250/月 [估]；燃气暖气（E 气候区）：年 €1,500-2,500 [估]
- 商用光纤：€25-40/月+IVA [实]
- TARI 垃圾税：Reggio 属全意最贵之列，150 m² 非住宅估 €800-1,500/年 [估-待核 Iren]
- 物业费：€50-200/月 [估]
- **租金外运营杂费合计 ≈ €350-700/月** [估]

## 市场学费基准

**少儿英语** [实]
- Helen Doron franchise：约 €15/课，月付 €70 起 + 注册费
- British Institutes（罗马参考）：儿童 €130 注册 + €1,050/年
- 结论：少儿团课 **€700-1,200/年（约 €10-18/课时）**

**中文** [实]
- ProntoPro 全国均值：少儿 **€18/课**（€16-25/小时）
- 罗马孔院少儿班：€350/年 50 小时（补贴价，€7/小时是地板价）
- Superprof 家教均值约 €18/小时

**钢琴** [实]
- 一对一均值 **€25-30/小时**，初学者 €18 起，少儿 €15-20
- 音乐学校实例：8 节 60 分钟一对一 = €177（约 €22/节）
- 集体音乐课：约 €8-15/小时/人 [估]

**少儿美术** [实]
- 私教均值 €18/课；团课约 €8/小时
- 机构实例：12 次×3 小时/季度 = €300；8 个月课程 €280

## 教师成本

- 雇员制（CCNL ANINSEI 私立学校）：VI 级 2026 年起最低 **€1,589.64 毛/月** + 十三薪；全额课时折算毛 €12-15/小时 [实/估]
- 兼课自由职业语言教师：市场惯例 **毛 €15-25/小时** [估]
- 家教/补课市场：€13-20/小时，英语 €16-35，北部偏高 [实]
- 音乐教师兼课：€15-25/小时 [估]；美术教师兼课 €12-18/小时 [估]

## 启动资本项

- 课桌（EN 1729 标准）：€45-59/张；椅子 €20-40；**12 人教室含教师桌/柜 ≈ €1,000-1,800** [实/估]
- 立式钢琴：Yamaha B1 新琴 €3,390-4,559；二手 Yamaha €1,950-4,990 [实]
- 数码钢琴（88 全配重）：新 **€400-550** [实]
- 65 寸交互触摸屏：**€1,170-1,630** [实]
- 轻装修：只刷漆 €8-12/m²；150 m² 表面翻新（漆+小工程）**€3,000-10,000** [估]
- ⚠️ 消防/无障碍/用途变更（agibilità、destinazione d'uso）合规改造费未含 [缺——见法律简报]

## 营销

- 网站：专业展示站 €1,200-2,500 一次性；域名+托管 DIY 约 €100/年 [实]
- 传单：1,000 张双面 A5 约 **€20-60** [实]
- 触达华人社区：**微信群 + 公众号 + 口碑是标准渠道（免费）**；朋友圈广告需大陆主体不适用；Meta/Instagram 本地广告小商户典型预算 €100-300/月 [估]
